# Biopharma Data Science Portfolio

This repository contains applied data science projects focused on
biopharmaceutical assay analytics, quality control, and experimental data interpretation.

The goal is to demonstrate realistic, industry-relevant data workflows rather than toy examples.

---

## Project: qPCR / ddPCR Control Trending

**Folder:** `qpcr-ddpcr-control-trending/`

This project simulates and analyzes control trending for qPCR/ddPCR assays,
similar to what is performed in regulated biopharma environments.

### What This Project Demonstrates
- Synthetic assay data generation
- Statistical control limits (mean ± 2 SD)
- Positive and negative control evaluation
- Automated pass/fail logic
- Trend visualization across assay runs
- Clear documentation and interpretation
